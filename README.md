# Color Defense — experimental iOS recovery

This repository preserves the recovered Color Defense app bundle and game resources from an experimental iOS recovery. It is an early baseline, not a completed remaster. The original game uses the Corona engine; its game logic is packaged in a compiled archive. Editable original source code and a modernized engine project are not currently available here.

The app identifies as `com.wireproof.colordefense` and displays as Color Defense. The experimental release includes an unsigned IPA, which requires the recipient's own signing and installation method. The recovered App Store package was thinned for older iPhone models. The baseline has been installed on an iPhone Duo and an iPad Pro as version 14, build 1.5; launch, gameplay, visuals, iPad asset coverage, and adaptive Duo resizing have not been verified. Installation alone does not establish compatibility.

`Payload/Color Defense.app` contains the recovered application resources and executable. Store licensing files, signing profiles, and signatures have been removed. The IPA is a preservation and testing artifact; it is not an iOS 27 SDK rebuild.
